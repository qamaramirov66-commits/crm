# VAYQEN CRM

LESEL BUSINESS учун CRM: лидлар, буюртмалар, тўловлар, ўлчов ва монтаж, ҳисоботлар, Jarvis овозли ёрдамчи.

## Файллар
- `index.html` — бутун илова (Supabase билан ишлайди)
- `sw.js` — офлайн режим ва хабарномалар учун service worker
- `supabase/migrations/` — база ўзгаришлари

## База янгиланиши (бир марта)
`supabase/migrations/20261029000000_crm_v2_features.sql` файлини Supabase → SQL Editor’да ишга туширинг.
У қўшади: қайта қўнғироқ санаси, алоқалар тарихи, маҳсулот/манба созламалари, менежер учун ўчириш,
ишлаб чиқариш роли, такрорланмас буюртма рақами, расм омбори, жонли янгиланиш.
Илова база янгиланмаган бўлса ҳам ишлайди — фақат шу имкониятлар яширин туради.
